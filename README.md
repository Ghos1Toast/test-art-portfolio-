Put artwork image files in this folder.

For each image, add a matching entry to data.js at the repo root —
set the "image" field to the exact filename (e.g. "low-tide.jpg").

Recommended before uploading:
- Resize so the longest edge is around 1600-2000px
- Export as JPG (or WebP) at ~80% quality
- Keep individual files well under 1MB where possible

This keeps the site fast to load and keeps the repo small.
